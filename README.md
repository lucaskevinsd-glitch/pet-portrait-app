# AI 宠物写真提示词生成器

上传宠物照片 → 填写宠物特征 → 选择写真风格、场景与图片参数 → 本地生成可直接复制到 Gemini 等生图工具中使用的高质量提示词。

## 核心：零 API 成本

- **不调用 Gemini API，不调用任何付费模型 API**。提示词全部由本地模板组装。
- **不需要 API Key**，没有任何环境变量需要配置。
- 前端、服务端、后台任务中均不存在模型 API 调用（已删除原服务端生图路由与费用预估模块）。
- 生成提示词不产生任何费用；真正的出图发生在用户自己使用的生图工具里，按该工具的计费规则结算。

## 功能

- 上传 1~5 张宠物照片（前端本地压缩到 1024px 内），点选主参考图，可清除全部
- 宠物特征卡（名字 / 品种 / 毛色 / 花纹 / 眼睛 / 耳朵 / 鼻子 / 脸型 / 体型 / 特殊标记），手动填写、手动确认
- **宠物身份特征锁定**：已填特征出现在主提示词最前面的「身份锁定」区块，声明为最高优先级；未填特征不编造，提示词要求生图工具以参考照片为准
- 8 种写真风格：P01 棚拍高级、P02 油画贵族、P03 韩系奶油、P04 花园梦幻、P05 电影感、P06 太空主题、P07 Q 版卡通、P08 水彩清新
- 场景参数：跟随风格默认 / 室内摄影棚 / 户外花园 / 居家客厅 / 户外草地 / 海边沙滩 / 雪地 / 城市街道
- 图片比例（1:1 / 3:4 / 4:3 / 9:16 / 16:9）、清晰度（1K / 2K / 4K），均写入提示词的输出要求
- 输出主提示词、负面提示词（通用防走样约束 + 风格专属负面词）、场景提示词、使用说明
- 切换风格 / 场景 / 参数后可重新生成提示词；参数变化后会提示预览已过期
- 每个提示词可一键复制、可直接编辑（编辑结果保留，直到下一次重新生成）；支持复制全部、下载完整 TXT 文件

## 提示词结构（每套）

1. 身份锁定：只写用户填写的特征；未填项不编造，要求以照片为准
2. 主体与构图：主体、姿态、构图
3. 场景：所选场景或风格默认场景
4. 光线与色彩：该风格的光线与配色
5. 毛发与面部细节：毛发、眼睛、面部细节的通用质量要求（不编造具体特征）
6. 输出要求：比例、清晰度、高清、无文字水印
7. 防走样约束：不改变身份特征，不添加不存在的花纹 / 饰品 / 第二只动物

## 隐私

- 照片只在浏览器内存里做本地预览，**不会上传到任何第三方服务**，不会写入服务器持久化存储。
- 不记录照片内容，不记录用户填写的信息；不接分析工具，不打含用户数据的日志。
- 关闭页面或点「清除全部照片」后，本地预览即被清理。
- **本网站不会分析照片**：所有特征都由用户对照照片手动填写；网站不会声称通过视觉模型识别了照片。

## 本地运行

```bash
npm install
npm run dev                  # http://localhost:3000
```

无需任何环境变量，无需 `.env` 文件。

## Vercel 部署

1. 把本仓库导入 Vercel（Framework Preset 选 Next.js，Build Command `npm run build`，Output Directory 默认）。
2. **不需要配置任何环境变量。**
3. Deploy。

## 测试说明

- 提示词生成逻辑可用 Node 对 `lib/` 做纯函数测试（见开发记录），覆盖：8 种风格、特征影响提示词、未填特征不编造、比例/清晰度进入提示词、场景切换、空输入、超长输入截断。
- 真实浏览器交互测试（上传、复制、TXT 导出、移动端布局）需在可公开访问的地址上验证；仅通过构建不能宣称已通过真实浏览器测试。
